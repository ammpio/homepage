# Documentation images

Put images used by docs pages in this folder (png, jpg, jpeg, webp, gif, svg, avif).
Reference them from a page with a relative path, for example:

```markdown
![Alert list in AMMP OS](../images/alert-list.png)
```

Keep file names lowercase with hyphens and images under ~500 KB. A reference to an image
that is not in this folder fails the docs check.
