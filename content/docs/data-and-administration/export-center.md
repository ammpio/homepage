The Export Center lets you download operational data for any or all assets in your portfolio. Open it via **Export Center** under **Data Management** in the left sidebar of the AMMP OS Portal.

## Exporting data

1. **Data type:** choose Energy data, Power data or KPI data.
2. **Interval:** the options depend on the data type:

   | Data type | Intervals |
   | --- | --- |
   | Energy data | Daily, monthly |
   | Power data | 15 minutes, hourly |
   | KPI data | 15 minutes, hourly, daily, monthly |

3. **Start and end date:** pick them in the calendars.
4. **Assets:** select one asset, several, or all of them.
5. **Time zone (optional):** tick **Export in asset's timezone** to export 15-minute and hourly data in each asset's local time.
6. Click **Create Export**. When the CSV is ready, click **Download**.

For data from a single dashboard panel, see [exporting from the Monitoring Center](./monitoring-center.md#exporting-data-from-a-panel). For automated or programmatic access, see [AMMP MCP server](./ammp-mcp-server.md).
