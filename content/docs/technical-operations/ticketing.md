AMMP Ticketing is a board-based task tracker built into AMMP OS. Use it to track maintenance work, turn alerts into tickets and assign work to your team. Tickets can also be created straight from [Alerting](./alerting.md).

## Adding a member to a board

> [!NOTE]
> Requires Editor permissions.

1. Click the members button to see the people in your organisation.
2. Select the person to add.
3. Choose their permissions on this board.

## Creating a list

> [!NOTE]
> Requires Editor permissions.

1. Scroll to the right and click **+ Add list**.
2. Type a name.
3. Click **Add List**.

## Creating a ticket

> [!NOTE]
> Requires Editor permissions.

1. In the list, click **+ Add card**.
2. Type a name for the ticket.
3. Click **Add card**.

## Working with a ticket

Click a ticket, or the pencil icon on it, to open its details.

| Field or action | What it does |
| --- | --- |
| Description | What the ticket is about |
| Tasks | A checklist of tasks |
| Actions | A work log for updates and notes. Users with Viewer (with Comment) permission can add to it too. |
| Members | Assign people from your organisation |
| Labels | Link the ticket to one or more assets, or create a new label |
| Due Date | Set a deadline |
| Stopwatch | Track time spent |
| Attachment | Attach a file from your computer |
| Subscribe | Get updates when the ticket changes |
| Move | Move the ticket to another project, board or list |
| Duplicate | Copy the ticket within the same list |
| Copy Link | Copy a shareable link to the ticket |
| Delete | Remove the ticket |

Editing a ticket requires Editor permissions, except where noted.

## Finding a ticket

Type the ticket name or ticket ID into the search bar.
